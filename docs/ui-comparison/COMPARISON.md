## 不能直接照搬的点

1. 原型顶部写生产 0.1.61，为历史示例；当前交接记录生产 0.1.71。任务负责人和人数也不是实时值。
2. 汇总写完成 4、需关注 3，而节点 status 为 done 3、attention 4。阅读版改为按节点标记显示 3，明确不是 Human 验收数。
3. 附件将“展示原型完成”放在任务已完成节点中；应区分局部实现、复测通过、结果提交和 Human 验收。
4. “完成时间”有“部分完成”这类状态文本；生产必须时间字段与状态分开。
5. 主任务→工作流→节点→讨论/证据不能成为新的多层容器或权限体系。Task 仍是唯一容器；工作分组只能是任务内视图。
6. 当前 Assignment 来源活动不一定是讨论，不能凭主题/正文猜测节点与派工关系。显示“尚未关联”，待显式 source_activity_id / assignment_id / run_id / result_id 关联。
7. “当前结论”必须注明来源、更新时间、Agent 整理/Human 确认、是否过时；没有可信数据时留清楚的空态，不能从聊天直接推断全任务完成或生成 Human 待办。
